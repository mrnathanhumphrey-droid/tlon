one door and left the other open.

⭐⭐ **AND IT FIRES ON SUCCESS.** A clean run writes `~/DONE`; the watchdog's
DONE branch terminates within one 300 s poll ("finishing work is not finishing
billing" — `tests/test_watchdog.py`). So the happy path always had a five-minute
collection window. `retrain12` SUCCEEDED and was terminated with 84 solo
transcripts still on it.

**pipeline stage**, so `~/DONE` means *persisted*, not *computed*. Then
terminate-on-DONE is correct rather than dangerous and the two systems never
need to agree about anything.
