## ⭐⭐ What the machinery learned (all live, all tested — 1681 passing)

1. **A probe proves the quantity it MEASURES, not the one you DEPEND ON.**
   `cmd_env` writes a tiny file and reports *"persist path verified writable"* —
   true, about the PATH, while the run depended on the CAPACITY. Rung 1b′
   attempt 1 trained 3,760 clean steps and died at `persist_leg1` on a storage
   quota. ⛔ **And the obvious server-side fix is vacuous too, TESTED not
   assumed**: HF's `preupload` takes a declared size and returns
   `uploadMode: lfs` identically for 24 GB and 1 KB — quota is enforced at
   COMMIT only. Fix = `tlon/act2/hub_capacity.py`, a floor before `train_leg1`.
2. **The ceiling is MEASURED, not typed.** The hub exposes no quota field, so
   the guard uses a bracket of two observations — `94,214,989,055 ≤ LIMIT <
   118,313,977,388` — and reads the LOW end. False-refuse is cheap;
   false-admit is the wall.
3. ⛔⛔ **"Findings live in current files" is a claim about NAMES.**
   `fw-s20624/weight_delta.json` was written three times to one path (NaN
   model, epoch 1, epoch 2), so rung 1a's epoch-1 baseline — **17.8117 / rms
   3.118e-4, what every dose-matched run compares against** — existed ONLY in
   superseded history and a squash would have destroyed it. Now
   `weight_delta_EPOCH1.json`, `_EPOCH2.json`, `_NAN_PRE_EAGER_FIX.json`.
4. **A whole-file text guard matches its own documentation.** Three times in
   one session (`prereg=`, `siblings`, and a truncated-fragment regex). Scope
   text guards to executable/semantic targets and red-proof against the
   docstring.
5. ⛔ **A test named for a refusal passed on a TRUNCATED FRAGMENT.** Greedy
   `[^\n]*` eats a line-continuation backslash, so
   `test_a_refusal_actually_stops_the_pipeline` would have passed with
   `|| true` on line two. Join continuations first.
