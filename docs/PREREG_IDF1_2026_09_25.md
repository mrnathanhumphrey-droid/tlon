## 0 · The hypothesis, stated as the thing that could be false

`read_lag` generates each turn from the bare prior surface only (`history=[]`;
PROVOCATION: *"You will be shown one Tlön utterance and nothing else."*). The
corpus achieves lag-2 suppression via `TTurn.inherited`, which never reaches a
training row.

**H-ID:** `release_w` as read by `read_lag` is **not a function of the model's
input**, so no training scope can install it; the D6 floor is the floor of the
best possible window-1 speaker, not a weight property.

**H-ID is what this probe can refute.**

⭐ Why the arithmetic makes this live: in a solo chain the model's input at turn
`t` is `t−1` and nothing else. **lag-1** is therefore carry from a turn the model
can see; **lag-2 and beyond are carry from turns it cannot see at all.** The −1
cell's own log states the object: *"⛔ lag 2 is the speaker's OWN previous
turn."* So a lag-2 reading at window-1 is **carry THROUGH `t−1`**, never
attention to an own turn in the window.

## 5 · Step 1 — identifiability (the decisive number)

Rebuild each dose corpus's chains from seed via `build_transient` so that
`TTurn.inherited` / `echoed` are available.

For every turn `t−1` with a non-empty inherited set, label each of its roots
**inherited / not-inherited**. Using **ONLY features readable from the `t−1`
surface** — root identity, position in surface, co-occurring roots, force,
surface length — fit a simple classifier (**logistic regression**, plus **one
gradient-boosted tree as a capacity check**) to predict inherited-ness.

⛔ **Split BY CHAIN, not by row.** A row-level split leaks chain identity.

Report **held-out AUC with a chain-bootstrap 95 % CI, per dose corpus.**

### A4′ · Cross-draw stability (replaces the literal-rows cross-check)

Fit on the dose-0 rebuild; evaluate on **a second independent rebuild at a
different seed**. Report AUC on both. If identifiability is a property of the
law rather than of a draw, AUC transfers. **A gap between draws is a finding
about A3's equivalence claim, not about H-ID.**

⛔ **Why A4 as originally written cannot run.** The trained-on rows carry no
chain identity (0a), and surfaces recur heavily: 15,573 provoke rows hold only
**5,263 distinct prompts**, and **76.90 %** of prompts have more than one
distinct successor. Walking `prompt → surface` forward crosses chains — a naive
reconstruction yields **62,356 triples where at most ~14,450 can be real**, a
4.3× inflation of fabricated `(t−2, t−1)` pairs. Chain identity was deliberately
destroyed, which is the same design decision H-ID is about.

### A4″ · Label-free check on the literal trained-on rows (secondary, no gate)

For every provoke row in `16abeb8d` — **single transitions only, no chain
reconstruction** — apply the A4′-fitted classifier to the prompt's roots.
Over all prompt roots compute:

```
a = P(root reappears in the response | classifier flags it inherited)
b = P(root reappears in the response | classifier flags it contributed)
```

Report `a`, `b` and `a − b` with a **row-bootstrap 95 % CI**. Compute the same
on the rebuild's rows.

**Readings (secondary, no gate):**
- `a < b` on the literal rows, matching the rebuild within CI → the rows the
  model saw carry the inherited-avoidance signal **in a form readable from
  `t−1`**. This is the one-step signal a window-1 learner could exploit, so it
  bears directly on **R2**.
- `a ≈ b` on the literal rows while the rebuild AUC is high → the classifier is
  reading something the trained-on draw lacks. **That is a finding about A3.**
- `a ≈ b` in both, with AUC ≈ 0.5 → consistent with **R1**. The avoidance exists
  in the corpus but cannot be seen from the surface.

## 7 · Pre-declared reading table — LOCKED BEFORE STEP 1 RUNS

Thresholds imported: `Z_LAGN_MAX = 3.0` from `transient.py`. Same-object noise
floor for model reads: lag-2 z ≈ 1.9.

- **R1 UNIDENTIFIABLE** — AUC 95 % CI upper `< 0.60` on the dose-0 corpus **AND**
  O-B's large-n lag-2 z `> 3.0`.
  ⇒ `release_w` at window-1 is **uninstallable by construction**. D6 "endogenous
  to base weights" → **DEVIATION: "endogenous to the window"**. Rung 1 is
  predetermined to floor, so **FSDP is not built for release**. The
  installation-resistance paper as framed is **void**. The art piece's path is an
  **INPUT change** (a window carrying own-chain state), not a weights change.
- **R2 IDENTIFIABLE** — AUC 95 % CI lower `> 0.75` **AND** O-B lag-2 z `≤ 3.0`.
  ⇒ release **is learnable from the input and the model under-uses it**. The
  floor is a genuine installation failure, the ladder is justified, and the paper
  **stands and gets stronger** ("the target was learnable, and five levers on two
  families failed").
- **R3 PARTIAL** — anything else. Report O-B's lag-2 as the **achievable floor**
  and restate every past release read as **model-minus-floor**. That gap, not
  `z ≤ 3.0`, becomes the quantity the ladder is judged on (**prereg deviation
  required before any further rung**).

**Secondary prediction of H-ID, recorded, not a gate:** O-E lag-2 is **flat**
across the three dose corpora (span comparable to the model's 1.26 z, nothing
like the corpus's 229.99), and O-E ≈ model within the matched-read distribution.
⛔ **If O-E tracks the corpus swing instead, H-ID is in trouble even if R1's AUC
condition holds.**
