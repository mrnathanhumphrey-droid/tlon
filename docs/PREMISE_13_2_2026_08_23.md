## Why a premise check at all

13.0 built the residue at the **grammar/metric** layer and red-proofed it there.
13.2 runs it through the **training loop** — `build_scene`, `ChannelPolicy`, the

## ⛔ ISSUE 1 — the build gap. `build_scene` never set a residue. **FIXED.**

`node()` constructed `EventNode(root=…, orient=…)` and never read
`pat.residue_any`. Every generated scene was residue-free, so `W_RESIDUE` was
**inert in the loop** and 13.0's landmine fix was **not reached by a single
run**. It would not have crashed: `residue.normalized(None, None)` is the legacy
0.0 path, so a residue arm would have behaved exactly like a no-residue arm and
Part 2 would have read empty — **the precise null-manufacturing failure the
ledger names as its fourth misreport risk, arriving through the one door the
ledger's own red-proof does not cover.**

**Fixed**, with the reproduction guard the fix needs:

> ⛔ **The residue draw is conditional on there being a choice to make.** Every
> phase 3–8 tool calls `build_scene`; an unconditional `rng.choice()` consumes a
> draw from the shared stream and silently stops all of them reproducing
> byte-identically. Sets with no `residue_any` (archive, v2, CR, TAO) draw
> **nothing**; a singleton draws nothing either.

Asserted on **rng state**, not on output — the residue does not render, so a
surface comparison could not have seen the draw. Red-proofed in the other
direction too (a multi-coordinate `residue_any` *must* draw), so the guard is a
real conditional and not a function that never draws.

**Also shipped:** the **third standing log**, `P3Stats.residues` — `{ref: {coord:
count}}` over built scenes. Part B's growth curve is a per-turn residue
statistic; unlogged it cannot be recovered after the run and **the curve does not
exist.** That is the 9.5 stall (effective sample size 0, not merely small) in a
new dimension, so the log goes in *before* the arms do. Output-only: no rng, no
gradient, same-seed runs still reproduce.

## ⛔⛔ ISSUE 2 — metric-vs-categorical has **no mechanism** in this architecture

Measured, not argued:

| where the metric could enter | can it? | evidence |
|---|---|---|
| speaker policy | **NO** | `ChannelPolicy.logits[ch]` is `(n_refs, n_values)` — one **independent** row per referent, indexed by `ref_idx` alone. Its own docstring: *"nothing shared, nothing forcing generalisation."* No parameter is a function of the residue coordinate. |
| listener input | **NO** | the surface is residue-invariant — that is 13.0's own renders-never red-proof. The listener **never perceives residue proximity**; it learns an arbitrary surface→index map. |
| M (comprehension) | **NO** | `m = probs[ri]`, hard identity. No partial credit for a near-miss residue. |
| free-channel capacity | **NO** | **24,500** distinct codes per referent (`aspect_root 7 · aspect_reps 4 · degree 7 · coda 5 · orient 25`). No capacity pressure at any realistic cluster size ⇒ an exact **arbitrary** code exists in both arms. |
| **R (novelty)** | **YES** | `W_RESIDUE * residue.normalized(...)` — the only route. |

**The steelman fails too.** Held-out generalisation is where a metric normally
buys something — but a referent the pair never co-adapted on has an **all-zero
policy row**, so the speaker emits a uniform-random code for it. A lookup table
**cannot interpolate between rows**. "Nearby residues get gestured at similarly"
is a *generalisation* claim, and generalisation is structurally unavailable to
this policy class.

> ⛔⛔ **Conventionability requires that at least one agent's representation be
> organised by the residue metric. Neither is. So the only live pathway is R — a
> novelty-pressure term — and a metric-vs-random difference measured this way is
> attributable to the two arms having different reward landscapes. That is a
> confound, not the mechanism.**

### ⭐ What this voids: **Part A rule 3, as written**

> *"Metric AND random both gap → metric is not the mechanism; stop and diagnose."*

Under a per-referent lookup table, **both arms gapping is the predicted default**,
and it licenses none of that conclusion. Locking rule 3 would have pre-committed
the phase to reading an architectural fact as a finding about ineffability.

⭐ Same shape as Lever 2's death and as Amendment A's own self-correction: **the
felt strength of a claim outrunning what the instrument can address.** Caught
pre-lock, for zero spend, which is what the prereg discipline is for.

## ⭐⭐ What SURVIVES, and it is the best news in the phase

**Part 2's core measurement is sound, and it is the first non-vacuous M in the
project.**

`phase3.py`'s own note: *"accuracy saturates at 100% immediately — the signature
core already determines the referent — and a constant term has zero gradient, so
the gate was never actually under test."* **Inside a residue cluster the
signature core does NOT determine the referent.** Measured at policy init on two
cluster-mates, independently sampled over a dense statistic:

- total variation between their surface distributions = **0.0425** (20 cells)
- ⇒ the **Bayes-optimal** listener is capped at **52.1 %** within the cluster
- **red-proof:** plant *"referent A always takes coda #0"* and the same statistic
  goes **0.0425 → 0.7985**, so the ≈0 is a measurement and not an artefact of
  seeding

*(The first version of this check re-seeded both arms identically and returned
TV = 0.0000 **by construction** — a statistic that could not have come back
positive. Recorded because it is the repo's own rule catching the repo's own
tool.)*

⇒ **The free channel has to carry real information for the first time, and
"does a pact form around an INEXPRESSIBLE distinction" is a live, non-vacuous,
never-before-asked question.** That part is worth running as designed.

## The three rulings needed

**1 · The metric-vs-categorical contrast.** Options, in the order I'd rank them:

- **(a) Make it testable — 2×2.** Add a *residue-conditioned* policy head (shared
  weights mapping the coordinate → channel logits) as a **configurable
  alternative** parameterisation, and run {metric, categorical} × {table,
  residue-head}. The prediction becomes sharp: **the arms should differ only
  under residue-head.** This turns the architectural claim above from an
  assumption into a measured result, and it is the only option that can come
  back and tell me I was wrong. Cost: a new policy class + 2× the cells.
- **(b) Scope it honestly.** Drop metric-vs-categorical; run Part 2 as "does a
  pact form around an inexpressible distinction"; demote the random arm to an
  **R-confound control** with a matched residue-distance distribution. Cheapest,
  fully sound, smaller claim.
- **(c) Run as specced.** Not recommended — spends seeds to rediscover a fact
  derivable from the policy class.

**2 · Seed count.** Prior sd = **3.54 pts** (phase-8 within-arm spread,
`runs/reset_dynamics.json`).

| n | MDE (pts) |
|---|---|
| 5 | 4.40 ← 10.0's quoted figure |
| **8** | **2.96** |
| 12 | 2.25 |
| 16 | 1.78 |

⛔ **The prior is weaker here than at 10.0 and the risk runs one way.** Phase 8's

optimistic. Table is a floor on n, not a ceiling.
