# ── THE RENTED-GPU ENVIRONMENT, AS MEASURED ON A WORKING BOX ─────────────
#
# ⛔⛔ THREE RUNS IN A ROW LOST TIME TO THE SAME SHAPE: the base image ships
# system packages that are TOO OLD for the pinned training stack, and each one
# surfaces as an ImportError from deep inside transformers, one stage at a time,
# with the meter running.
#
#   Pillow 9.0.1   → `module 'PIL.Image' has no attribute 'Resampling'`
#                    (raised from transformers.image_utils, while importing PEFT)
#   Jinja2 3.0.3   → `apply_chat_template requires jinja2>=3.1.0`
#                    (raised only when the model is first PROMPTED — so it
#                     survives install, survives import, and detonates at the
#                     first real generation)
#   numpy 1.21.5   → `TypeError: 'type' object is not subscriptable` from
#                    `DataCollatorForLanguageModeling`'s CLASS BODY, which
#                    annotates `np.ndarray[...]`. `np.ndarray.__class_getitem__`
#                    arrived in numpy 1.22.
#
# ⛔⛔ AND THE NUMPY ONE IS A CORRECTION TO THIS FILE'S OWN EARLIER TEXT. An
# earlier revision said numpy 1.21.5 "was left alone … and worked". It did not
# work. It had never been EXERCISED: the gate path never imports the collator,
# only the trainer does, so the first thing to touch it was stage 5 — after the
# baseline had already passed and with the meter running. **Absence of a failure
# on an unexercised path is not evidence the path works; it is the absence of a
# test.** The lesson is not "pin numpy too" — it is that a version claim must
# name what exercised it.
#
# ⭐ THE JINJA ONE IS THE INSTRUCTIVE CASE: nothing catches it until something
# actually calls the chat template. `pip install` succeeds, `import transformers`
# succeeds, the model LOADS — and then the first generation dies. That is why the
# pipeline keeps a BASELINE stage that runs the real gate on the untuned model
# before the fine-tune: it is the cheapest stage that exercises the whole call
# path, and it caught this for ~$0.30 instead of ~$2.50 after a 66-minute train.
#
# Install in THIS ORDER on a fresh Lambda box:
#
#   pip install -q --upgrade Pillow 'jinja2>=3.1.0'
#   pip install -q -r requirements-lambda.txt
#   python -c "from transformers import AutoTokenizer; \
#       t=AutoTokenizer.from_pretrained('Qwen/Qwen2.5-7B-Instruct'); \
#       print(t.apply_chat_template([{'role':'user','content':'x'}], tokenize=False))"
#
# ⛔ THAT LAST LINE IS NOT OPTIONAL. It is the smoke test for the failure that
# import-time checks cannot see. Ask the live path a real question.
